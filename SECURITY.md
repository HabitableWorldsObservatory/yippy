# Security policy

This is research software maintained by one person. Please report a vulnerability, for
example a leaked credential, a malicious dependency, or a workflow that could be abused, through
GitHub private vulnerability reporting: use "Report a vulnerability" on the Security tab of this
repository. If that is unavailable, email corey.a.spohn@nasa.gov with "SECURITY" in the subject.

Expect an acknowledgement within a week. Only the latest release receives fixes. Incorrect
numerical results are not security issues; please open an ordinary issue for those.
